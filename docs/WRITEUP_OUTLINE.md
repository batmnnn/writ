1. Title and one line: "Writ: company cards for AI agents that can't spend past the task, the team budget or the cash reserve."

3. What the samples lack (80 words): awx-devx/airwallex-agent-cards and awx-devx/airwallex-agentic-banking-aws already do "agent proposes, code decides, human approves". Writ adds one team pool across agent cards, a reserve check against the live balance, a taint freeze the agent can't hide, and the deciding code in an attested enclave. In the AWS kit an adapter Lambda holds the Airwallex secret.
4. How it works (150 words): a writ is one merchant, one MCC, one amount in cents, USD, an expiry, signed with Ed25519 on the approver's device. decide() checks signature, hash, expiry, single use, currency, MCC, merchant, amount, taint, team pool, balance age, reserve floor. On a yes the enclave writes a signed checkpoint to S3 Object Lock, then arms the frozen card for that amount, MCC and currency, and disarms after one swipe. Airwallex refuses anything else.
